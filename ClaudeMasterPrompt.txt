LATEX FEATURES THAT MAY IMPRESS THE JUDGES:

HIGH-WOW FEATURES
1. TikZ diagrams
   → Create polished diagrams/flowcharts entirely in LaTeX.

2. Beamer overlay animations
   → Reveal elements progressively as you speak.
   → Use \only, \uncover, \visible, \onslide, <1->, <2->, etc.

3. Animated TikZ diagrams
   → Build a process visually step-by-step rather than showing everything at once.

4. Progressive visual transformation
   → Make one visual evolve through stages instead of switching to separate slides.
   → Example: raw data → codes → clusters → themes.

5. Recursive / feedback-loop diagrams
   → Use curved TikZ arrows to show iteration and refinement.
   → Particularly useful because RTA is recursive rather than a rigid pipeline.

6. Side-by-side animated comparison
   → Reveal two interpretations/lenses sequentially.
   → Useful for demonstrating different researcher perspectives.

7. Highlighting + dimming
   → Highlight the relevant part of a diagram/text while fading everything else.

8. Layered TikZ graphics
   → Background → structure → arrows → labels → highlights appear in layers.


ADVANCED VISUAL TECHNIQUES
9. Custom TikZ nodes
   → Rounded boxes, circles, labels, icons, custom shapes.

10. Precise TikZ positioning
    → Professionally align complex diagrams without manually positioning objects.

11. Transparency
    → Fade secondary information and emphasize the current concept.

12. Clipping
    → Reveal only selected regions of a diagram.

13. Custom arrows / paths
    → Curved arrows, feedback arrows, connectors, directional relationships.

14. Before → after visual transformations
    → Turn an initial concept into a refined concept through overlays.

15. Zoom / focus effects
    → Move attention from a large overview into one specific component.


FEATURES THAT DEMONSTRATE LATEX MASTERY
16. Custom Beamer theme
    → Custom colors, typography, title page, footer/header, spacing.

17. Custom commands
    → Define reusable commands for recurring visual components.

18. Custom environments
    → Create your own styled boxes/components.

19. Advanced Beamer overlays
    → Precise control over what appears on each click.

20. Columns / structured layouts
    → Clean comparison and multi-part layouts.

21. Custom blocks
    → Styled blocks, alertblocks, examples, definitions, etc.


ACADEMIC LATEX FEATURES
22. BibLaTeX / BibTeX
    → Proper academic references and citations.

23. Automatic references
    → Automatically format authors, years, titles, DOI information, etc.

24. Cross-references
    → \label + \ref for consistent internal references.

25. Mathematical notation
    → Use LaTeX's mathematical typesetting for conceptual equations.

26. Professional tables
    → booktabs for clean academic tables.
